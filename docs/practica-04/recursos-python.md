### Investigación de Recursos de Python
---
*1. ¿Qué es la documentación oficial de un lenguaje de programación?*
Es el conjunto de guías y explicaciones publicadas por los creadores de un lenguaje de programación para enseñar cómo funciona y cómo utilizarlo correctamente.

*2. ¿Qué información puede encontrarse en ella?*
* **Tutoriales para principiantes:** Introducción a la sintaxis y conceptos básicos.
* **Referencias del lenguaje:** Explicación detallada de la sintaxis y palabras reservadas.
* **Librería estándar:** Guía de todos los módulos y funciones integradas.
* **Novedades y cambios:** Notas sobre nuevas versiones, funciones añadidas o descontinuadas.
  
*3. ¿Cómo puede ayudar a resolver dudas sobre variables, listas, diccionarios, ciclos y funciones?*
Permite consultar cómo se utilizan estos elementos, conocer su funcionamiento y revisar ejemplos de código que ayuden a resolver problemas al programar.

*4. ¿Qué diferencia existe entre consultar documentación oficial y utilizar una respuesta públicada en un foro?*
La documentación oficial ofrece información publicada y mantenida por los responsables del lenguaje. En cambio, los foros contienen respuestas de otros usuarios que pueden ser útiles, pero es necesario comprobar si son correctas y están actualizadas.

### Recursos de Python
---
**Recurso 1:** The Python Tutorial
* **Nombre del recurso:** El tutorial de Python
* **URL:** https://docs.python.org/3/tutorial/
* **Tema que aborda:** Conceptos básicos del lenguaje Python (variables, control de flujo, estructuras de datos, funciones y módulos)
* **Tipo de información que ofrece:** Explicaciones conceptuales, reglas de sintaxis y ejemplos de código interactivo.
* **Utilidad para el proyecto integrador:** Sirve com base para repasar la sintaxis correcta al contruir scripts de automatización en Python.
* **Ejemplo de una situación en la que lo consultarías:** Cuando tengamos dudas sobre cómo utilizar alguna instrucción de Python o no recordemos cómo funciona un elemento del lenguaje.

**Recurso 2:** Estructuras de datos
* **Nombre del recurso:** Estructuras de datos
* **URL:** https://docs.python.org/es/3/tutorial/datastructures.html
* **Tema que aborda:** Uso de listas, tuplas, diccionarios y otras estructuras de datos en Python.
* **Tipo de información que ofrece:** Explicaciones y ejemplos de cómo almacenar, organizar y manipular datos.
* **Utilidad para el proyecto integrador:** Permite organizar información de dispositivos de red y acceder a sus datos fácilmente.
* **Ejemplo de una situación en la que lo consultarías:** Cuando se necesite crear una lista de dispositivos de red y guardar direcciones IP y estados en un diccionario.
