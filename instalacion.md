# Instalación

## Python

Se instaló Python para desarrollar y ejecutar los scripts utilizados durante la práctica de automatización de redes.

## Visual Studio Code

Se instaló Visual Studio Code como entorno de desarrollo para escribir y editar los archivos del proyecto.

## Git

Se instaló Git para administrar las versiones del proyecto y trabajar con el repositorio de GitHub.

## GitHub

Se utilizó GitHub para almacenar el proyecto y compartir los archivos y la documentación del equipo.

## Postman

Se instaló Postman para realizar pruebas mediante solicitudes y comprobar el funcionamiento de los servicios utilizados durante la práctica.

## OpenConnect GUI

Se instaló OpenConnect GUI para trabajar con la conexión VPN necesaria durante la práctica.

## Docker

Se instaló Docker para trabajar con contenedores dentro del entorno de infraestructura.

## GNS3

Se instaló GNS3 GUI para realizar las actividades relacionadas con la simulación y configuración de redes.

## GNS3 VM

Se preparó GNS3 VM como parte del entorno necesario para ejecutar los dispositivos y componentes virtualizados utilizados en GNS3.

## VMware

Se instaló y utilizó VMware para ejecutar GNS3 VM.

## Resultado

Al finalizar la instalación se contó con las herramientas necesarias para continuar con la configuración y las pruebas de la estación de automatización de redes.
